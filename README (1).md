# Открытые вебинары Maytoni для партнёров

Страница с расписанием открытых вебинаров. Данные берутся из Google-таблицы
«Расписание вебинаров для сайта» при каждом открытии страницы, поэтому сайт
обновлять не нужно: тренеры меняют только таблицу.

В репозитории один рабочий файл: `index.html`. Шрифты, логотип и стили уже внутри него.

## Как это работает

1. Тренеры заполняют Google-таблицу (одна строка — один вебинар).
2. `index.html` при открытии загружает таблицу и строит расписание.
3. Ссылка на Zoom из таблицы показывается партнёрам за 3 часа до начала вебинара.
4. Прошедшие вебинары скрываются автоматически.
5. Если таблица недоступна, страница показывает сохранённую копию расписания и сообщение об этом внизу.

## Первоначальная настройка

### 1. Открыть таблицу для чтения

Страница может прочитать таблицу, только если она открыта для просмотра.

В Google-таблице: **Настройки доступа → Общий доступ → «Все, у кого есть ссылка» → роль «Читатель»**.

Тренерам выдайте роль **«Редактор»** по их почтам. В настройках доступа (значок шестерёнки)
снимите галочку «Редакторы могут изменять разрешения», чтобы доступ не раздавали дальше.

Ссылка на таблицу уже прописана в `index.html`, в переменной `SHEET_URL`.

### 2. Разместить страницу на GitHub Pages

1. Создайте репозиторий (или используйте существующий) и загрузите в корень файл `index.html`.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: Deploy from a branch**,
   ветку **main** и папку **/ (root)**, нажмите **Save**.
4. Через 1–2 минуты страница откроется по адресу вида
   `https://<имя-аккаунта>.github.io/<имя-репозитория>/`.

Эту ссылку можно рассылать партнёрам: регистрация для просмотра не нужна.

### 3. Свой адрес (по желанию, делает IT)

Чтобы страница открывалась, например, по адресу `webinars.maytoni.ru`:

1. В **Settings → Pages → Custom domain** впишите адрес и сохраните.
2. У регистратора домена добавьте CNAME-запись: `webinars` → `<имя-аккаунта>.github.io`.
3. После проверки включите **Enforce HTTPS**.

## Перенос в другой репозиторий

Скопируйте `index.html` (и этот README) в новый репозиторий и повторите шаг 2.
Если ссылка на страницу изменится, обновите её в рассылках и в личном кабинете партнёра.
Своё доменное имя (шаг 3) позволяет переезжать без смены ссылки.

## Если нужно сменить таблицу

Откройте `index.html` и замените ссылку в строке:

```js
var SHEET_URL='https://docs.google.com/spreadsheets/d/.../edit#gid=0';
```

Подходит обычная ссылка из адресной строки таблицы или ссылка из
«Файл → Поделиться → Опубликовать в интернете» в формате CSV.

Порядок столбцов в таблице менять нельзя:
Дата · Начало (МСК) · Окончание (МСК) · Тема · Спикер · Статус · Регистрация (Timepad) ·
Zoom для незарегистрированных · Zoom: идентификатор · Zoom: код доступа · Комментарий.

## Как часто обновляются данные

Страница загружает таблицу при открытии, при возвращении на вкладку и каждые 5 минут, пока вкладка открыта.

Учтите: ссылка на Zoom скрыта на странице до момента «за 3 часа до начала», но сама таблица
открыта для чтения по ссылке, поэтому технически ссылка доступна раньше.
